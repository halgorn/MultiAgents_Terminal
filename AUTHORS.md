## How to Get Listed

Contributors are added here when they:
1. Merge a PR that lands in a release.
2. File a security advisory that results in a CVE / GHSA.
3. Author or significantly contribute to a sector in `docs/SPEC-V1.md`.

If you've contributed and don't see your name, open a PR adding yourself to this file.
